Title:  
Library Chatbot & Admin Panel

Description:  
A Flask‑based library management system with a chatbot interface for students to search, borrow, and return books, and an admin dashboard to manage inventory, track transactions, and view statistics.

Features:

Student login with secure sessions

Chatbot for book search, borrow, and return

Transaction history for each student

Admin panel with CRUD operations on books

Subject‑wise statistics and inventory overview

Tech Stack:

Backend: Python, Flask

Database: SQLite

Frontend: HTML, CSS, Jinja2

Setup Instructions:

Clone the repository

Install dependencies: pip install flask

Initialize the database using setup_db.py or schema.sql

Run the app: python app.py

Open http://127.0.0.1:5000 in your browser
